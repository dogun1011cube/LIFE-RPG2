# 픽셀시티 (PixelCity)

마인크래프트처럼 네모난 블록으로 만든 3D 도시 건설 게임이에요. 플레이 방식은 심시티와 같아요.
빌드 도구 없이 `index.html` 하나로 실행돼요. 3D 엔진인 three.js는 CDN에서 불러와요.

## 실행
- GitHub Pages: `https://<사용자>.github.io/<저장소>/simcity/`
- 로컬: 저장소 폴더에서 `python3 -m http.server` 실행 후 `http://localhost:8000/simcity/` 접속
  (ES 모듈을 쓰기 때문에 `file://`로 직접 열면 동작하지 않아요)

## 조작
| 입력 | 동작 |
|---|---|
| `1`~`6` | 살펴보기 · 도로 · 주거 · 상업 · 공업 · 철거 |
| 왼쪽 드래그 | 도구 사용 (도로는 L자, 구역/철거는 사각형) |
| 오른쪽 드래그 / `Q` `E` | 회전 |
| 휠 / `+` `-` | 확대·축소 |
| `WASD` / 방향키 / 가운데 드래그 | 이동 |
| `Space` | 일시정지 |
| 모바일 | 한 손가락 = 도구, 두 손가락 = 이동·확대 |

## 게임 규칙 (1~2단계)
- 도로에서 3칸 안에 있는 구역에만 건물이 들어서요.
- **RCI 수요**: 일자리가 남으면 주거(R) 수요가, 노동력이 남으면 공업(I)·상업(C) 수요가 올라가요.
  세율이 높을수록 모든 수요가 줄어들어요.
- 건물은 Lv.1에서 Lv.3까지 자라요. 높은 단계로 올라가려면 도시 인구와 주변 건물 밀도가 필요해요.
- 세금은 매달 걷히고, 도로 유지비가 빠져나가요. 매달 자동 저장돼요.

## 구조
```
simcity/
  index.html, style.css
  src/
    main.js      게임 루프, 저장/불러오기
    config.js    밸런스 수치
    world.js     맵 데이터, 지형 생성
    sim.js       수요, 성장, 세금
    tools.js     도구별 범위·비용 계산
    scene.js     three.js 렌더링 (지형 청크, 인스턴싱, 구름, 연기)
    textures.js  코드로 그리는 픽셀 텍스처 아틀라스
    voxel.js     복셀 메시 생성 (면 컬링 + 앰비언트 오클루전)
    models.js    건물 27종, 나무, 바위 모델
    ui.js, input.js
```
