# LIFE RPG

**현실의 공부가 캐릭터를 성장시키는 레트로 픽셀 RPG.**
공부하고 → 기록하고 → EXP·골드·기력을 얻고 → 강해져서 → 몬스터를 쓰러뜨리고 → 100층 탑을 오른다.

React + TypeScript + Vite로 만든 브라우저 게임이며, 모든 진행 상황은 브라우저(localStorage)에 자동 저장됩니다.

---

## 실행 방법

```bash
npm install        # 최초 1회
npm run dev        # 개발 서버 → http://localhost:5173
npm run build      # 배포용 빌드 → dist/
npm run preview    # 빌드 결과 미리보기 → http://localhost:4173
npm test           # 게임 로직 테스트 + 밸런스 시뮬레이션
```

### GitHub Pages 배포

`.github/workflows/deploy.yml`이 `main` 브랜치에 push될 때마다 테스트 → 빌드 → Pages 배포를 수행합니다.
처음 한 번만 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿔 주세요.
(예전처럼 저장소 루트의 `index.html`을 직접 서비스하는 방식은 더 이상 동작하지 않습니다 — 빌드가 필요합니다.)

## 게임 시스템

| 시스템 | 내용 |
| --- | --- |
| **공부 기록** | 과목 + 시/분/(초). 기록은 항상 **더해짐** (덮어쓰지 않음). RPG 하루당 최대 24시간. 스톱워치(새로고침해도 유지), 오늘 기록 삭제 시 보상 회수 |
| **보상** | 1분 = EXP 1 · 골드 0.5 · 10분마다 기력 1 · HP/MP 1% 회복. 연속 달성 보너스(하루 +2%, 최대 20%), 장비/두루마리 보너스 |
| **과목 훈련** | 같은 과목 2시간마다 능력치 +1 (국어·화학 → INT, 물리·지구과학 → STR, 수학·영어 → DEX, 생명과학·한국사·사탐·제2외국어 → LUK). 직접 만든 과목은 능력치를 고를 수 있음 |
| **과목** | 새 게임은 수능 과목(국어·수학·영어·한국사·과탐 Ⅰ/Ⅱ·사회탐구·제2외국어/한문)으로 시작. `화2` = `화학Ⅱ` = `화학2` = `Chemistry II` 자동 통합, `생2`·`물1` 등 약칭 지원. 과목 추가·삭제(기록은 유지, 다시 입력하면 복구)·수능 과목 불러오기 |
| **RPG 하루** | 자정에 절대 리셋되지 않음. **하루 마감 → 잠들기 → 일어나기** 로만 다음 날이 시작. 잠들기 취소 가능 |
| **연속 달성** | 일일 목표(설정에서 변경)를 채우고 잠들면 +1일. 목표를 못 채우면 초기화 |
| **레벨/능력치** | EXP 곡선 `25 × (Lv−1)^1.85`, **레벨 상한 없음**. 공격력·마법공격력은 레벨에 비례(레벨 × 10 + 힘/지능 + 장비). HP·MP·DEF·CRIT·STR·INT·DEX·LUK |
| **랭크** | F → … → SSS 명예 랭크. 조건(레벨·탑 층·보스 수)이 기존의 **1,000,000배** (`src/data/ranks.ts`의 `RANK_DIFFICULTY`) |
| **해금 단계** | 상점 품목·지하묘지·투기장·탑 봉인(21/41/61/81층)·기력 최대치는 랭크 대신 원래 기준(예: Lv 10 · 탑 10층 · 보스 1종)으로 열림 |
| **전투** | 턴제: 공격 / 스킬(8종) / 아이템 / 방어 / 도망. 치명타, 버프·저주·중독·방어력 감소. **몬스터마다 고유 스킬 + 궁극기**(HP 50%에서 예고 후 발동, 보스는 25%에서 한 번 더 — 예고 턴에 방어) |
| **탑** | 100층 + 무한. **N층 몬스터 = Lv N**(체력·공격력·방어력 대폭 강화). 5층마다 정예, 10층마다 보스, 보물·이벤트·상인 층, 21/41/61/81층 봉인 |
| **특별 층** | **4층 死 망자의 회랑**(3연전·회복 절반·죽음의 선고) · **7층 행운의 전당**(슬롯머신 + 황금 슬라임 킹) · **13층 금기의 층**(지식 퀴즈로 봉인 해제 + 파멸의 시계 보스) |
| **월드맵** | 마을, 훈련장(무료 연습), 속삭이는 숲, 잊혀진 지하묘지(랭크 D), 투기장(랭크 C + 13층) |
| **상점** | 무기·방어구·장신구·소모품·특수(보물상자, 현실 보상 쿠폰). 매일 바뀌는 특가, 판매, **모두 판매**(장비만/전체, 장착·잠금 아이템 제외). 아이템 **우클릭 = 잠금** |
| **장비/강화/합성** | 무기·투구·갑옷·장갑·신발·장신구×2, 6단계 희귀도. 대장간 +1~+10 강화. 같은 등급 장비 3개 + 골드 → 한 단계 높은 등급 장비 합성(같은 부위 3개면 같은 부위, 10% 대성공) |
| **가챠** | 1회 150G / 10회 1350G(희귀 이상 확정), 확률 공개, 60회 천장, 외형(칭호·망토·오라), 기록. 자동 소환(1회 250G, 목표 등급·최대 횟수 지정, 골드가 떨어지면 정지) |
| **퀘스트** | 일일 퀘스트(새 RPG 하루마다 갱신, 미수령 보상 자동 지급) + 장기 업적 |
| **저장** | 자동 저장 + 수동 저장, 백업 슬롯, 하루 단위 스냅샷, JSON 내보내기/불러오기, `RESET` 입력 확인 후에만 초기화 |

### 이전 버전(v2) 데이터
같은 브라우저에 LIFE RPG v2 세이브(`lifeRpg2_state_v1`)가 있으면 타이틀 화면에서 **이전 데이터로 이어하기**가 나타납니다.
공부 기록·과목·Day·EXP는 그대로, 골드는 새 경제(1분 = 0.5G)에 맞게 소급 환산, 옛 "층"은 기력으로 바뀝니다.
이전 세이브 키는 **읽기만 하고 절대 지우거나 수정하지 않습니다.**

## 구조

```
src/
  data/       게임 데이터 (과목·아이템·몬스터·스킬·퀘스트·랭크·월드/가챠/퀴즈)
  game/       순수 게임 로직 (UI와 분리, 테스트 가능)
    study.ts  day.ts  progression.ts  battle.ts  encounters.ts  tower.ts
    shop.ts   inventory.ts  quests.ts  loot.ts  core.ts  state.ts
  store/      불변 상태 스토어(immer) + 저장/백업/마이그레이션
  render/     캔버스 픽셀아트 (스프라이트, 전투 씬, 탑, 배경)
  audio/      WebAudio 칩튠 효과음
  ui/         React 화면 · 오버레이 · 컴포넌트
legacy/       v2 원본 파일 (참고용)
```

새 몬스터·아이템·퀘스트는 `src/data/*.ts`에 항목을 추가하는 것만으로 게임에 반영됩니다.

단축키: `1`~`0` 메뉴 이동 · 전투 중 `1`~`5` 명령 · `Esc` 뒤로.
